# Notes

Concept notes **in my own words**, one file per concept (e.g. `tokens-and-context.md`, `mcp.md`, `rag-chunking.md`).

Each note answers:
1. What is it, in two sentences?
2. Where does it show up in my projects?
3. A tiny example (code or prompt).
4. What I got wrong at first.

AI can quiz me on these. It never writes them.
