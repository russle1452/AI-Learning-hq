# Evals

Model comparison results and monthly verdicts.

- `arena-YYYY-MM-DD.md` — Model Arena runs (Phase 1+)
- `YYYY-MM.md` — **Monthly new model day** (first weekend, 60 min):
  1. What shipped last month (models, features, tools)
  2. The one most relevant to my projects
  3. Run it through Model Arena / eval harness on real tasks
  4. One-paragraph verdict: better, worse, or different — and for what

Use synthetic or public data only when testing free tiers.
